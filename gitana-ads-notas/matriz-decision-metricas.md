# Matriz de Decisión: ¿Qué hacer según tus métricas?

| Situación actual | Próxima acción recomendada |
|---|---|
| Menos de 1.000 seguidores en IG/FB | Campañas de Tráfico al perfil y de Interacción |
| Seguidores OK pero eventos del píxel bajos | Campañas de tráfico al Perfil y conversión para alimentar el pixel |
| Seguidores y pixel con buen volumen | Crear audiencias personalizadas, con sus Lookalikes correspondientes |
| Pixel sin datos de compra suficientes | Usar Add to Cart como evento base para Lookalikes o escalar lento hasta completar |
| Nada de lo anterior | Volver a base: contenido, comunidad, tráfico frío |

## Conclusión

Este módulo no solo te enseña a leer números: te da una foto clara de tu negocio. Ideal para que te posiciones y tomes una decisión en base a datos y no de forma subjetiva.

Si tus métricas no acompañan, escalar no es una opción. Y si están listas... es momento para empezar a hacerlo.
