# Fuentes de ofertas y cómo usarlas

## Buscadores (precio real)
| Herramienta | Para qué |
|---|---|
| Google Flights | Grilla de fechas, gráfico de precios, "Explorar" (mapa a cualquier destino), indicador de precio bajo/típico/alto, alertas. |
| Skyscanner | "A todas partes", "mes entero", muestra agencias chicas; cambiar país del sitio. |
| Kayak / Momondo | `-flexible-3days`, hacker fares (combina solo idas de distintas aerolíneas), alertas. |
| Kiwi.com | Itinerarios "virtual interlining" (split armado por ellos, con garantía propia). Leer condiciones de la garantía. |
| Turismocity (AR) | Comparador local con alertas y calendario de precios en pesos. |
| Sitios de aerolíneas | Promos exclusivas, tarifas con millas, cambiar país de venta. |

## Error fares / promos (publicadas por cazadores)
| Fuente | Notas |
|---|---|
| Secret Flying | Error fares y ofertas globales, filtrables por origen (incluye salidas desde Sudamérica). |
| The Flight Deal / Fly4free | Ofertas EE.UU./Europa; útiles para tramos internos tras un split. |
| Promociones Aéreas (AR) | Comunidad argentina de ofertas y promos de millas. |
| Going / Jack's Flight Club / Thrifty Traveler | Newsletters de alertas (pago para lo mejor). |
| FlyerTalk (foro "Mileage Run Deals") | Donde se detectan error fares primero. |
| Reddit r/awardtravel, r/flights | Sweet spots de millas y reportes. |
| Canales de Telegram/Instagram de ofertas | Muchos cazadores argentinos publican ahí; buscar "ofertas vuelos telegram argentina". |

## Patrones de búsqueda (WebSearch)
- `site:secretflying.com "Buenos Aires" [mes año]`
- `site:promocionesaereas.com.ar [destino]`
- `"error fare" [origen o país] [mes año]`
- `promo smiles [mes año]` · `flying blue promo rewards [mes año]`
- `[aerolínea] sale [mes año]` · `[ruta] precio más bajo histórico`
- `fifth freedom flights [ciudad]`
- `stopover program [aerolínea] [año]`

## Reglas de verificación
1. Toda tarifa citada: fuente + fecha/hora de consulta.
2. Las ofertas de blogs suelen expirar en horas: re-verificar en el buscador antes de recomendar.
3. Diferenciar "precio visto en caché" (Aviasales/Travelpayouts, Skyscanner "estimado") de "precio confirmado".
